# VirtualPet_12
一款 Java Swing + SQLite 虚拟电子宠物桌面养成软件，结合待办打卡任务，游戏化督促自律学习。

## 项目简介
本项目是单机桌面模拟程序，将电子宠物养成和待办打卡结合。完成任务宠物状态提升，超时任务会让宠物状态下降，支持宠物自动成长进化，所有数据通过SQLite持久化保存，关闭程序不会丢失存档。

## 技术栈
语言：Java
GUI：Java Swing
数据库：SQLite
构建工具：Maven

## 核心功能
1. 宠物状态系统：饱食度、心情、清洁度随时间自动衰减
2. 任务联动打卡：新增待办、按时完成加分、超时扣分
3. 宠物成长进化：经验积累，幼年→成年形态切换
4. 持久化存档：自动读写SQLite数据库，退出保留进度
5. 基础交互：喂食、清洁、切换宠物图片
